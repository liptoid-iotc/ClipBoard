# Clipboard Manager (C / GTK3 / X11)

مدير حافظة (Clipboard) بسيط وخفيف لمستخدمي لينكس، مكتوب بلغة C.

## المزايا
- **Alt+L** لفتح/إغلاق النافذة من أي مكان (اختصار عام عبر X11).
- يدعم **النصوص والصور** المنسوخة.
- حذف تلقائي للعناصر بعد مدة قابلة للتعديل (افتراضي 30 دقيقة) من داخل الواجهة نفسها.
- **بدون حد أقصى** لعدد العناصر.
- تحديد متعدد بـ **Ctrl+Click** لحذف أو نسخ عدة عناصر دفعة وحدة.
- زر **Clear All** لمسح كل شيء فوراً.
- ضغطة عادية على أي عنصر = نسخه فوراً للحافظة (تقدر تعمل Ctrl+V بأي مكان مباشرة).
- يشتغل تلقائياً مع بدء تشغيل الجهاز (autostart).
- التخزين المؤقت في `/tmp/clipboard-manager` (يُمسح تلقائياً عند إعادة التشغيل، لأنه tmpfs).

## ⚠️ المتطلبات المهمة
هذا التطبيق يعتمد على **X11** (عبر Xlib لتسجيل الاختصار العام). لأنك ذكرت أنك تستخدم
`gnome-flashback`، فهذا عادة يعني أن جلستك تعمل على X11 وليس Wayland — ممتاز، لأن
التطبيق سيعمل بشكل طبيعي.

**لن يعمل الاختصار العام (Alt+L) على جلسات Wayland النقية** (مثل GNOME الافتراضي الحديث)
لأن Wayland يمنع البرامج من مراقبة لوحة المفاتيح عالمياً لأسباب أمنية. باقي الميزات (النسخ،
اللصق، الحذف التلقائي) ستعمل، لكن فتح النافذة سيحتاج طريقة بديلة (مثل ربطها باختصار عبر
إعدادات النظام بدلاً من XGrabKey الداخلي).

## البناء (Build)

تحتاج مكتبات التطوير الخاصة بـ GTK3 و X11:

```bash
# Ubuntu / Debian
sudo apt install build-essential libgtk-3-dev libx11-dev pkg-config

# Fedora
sudo dnf install gcc gtk3-devel libX11-devel pkgconf-pkg-config

# Arch (إذا حبيت تجربه بس المشروع مو مخصص له)
sudo pacman -S base-devel gtk3 libx11
```

ثم:
```bash
make
```

سينتج ملف تنفيذي باسم `clipboard-manager` في نفس المجلد.

## التشغيل السريع (بدون تثبيت)
```bash
./clipboard-manager &
```
ثم اضغط **Alt+L** لفتح النافذة من أي مكان.

## التثبيت الدائم + بدء تلقائي (بدون صلاحيات root)
```bash
chmod +x install.sh
./install.sh
```
هذا السكربت:
1. يبني المشروع.
2. ينسخ الملف التنفيذي إلى `~/.local/bin/clipboard-manager`.
3. ينشئ ملف autostart في `~/.config/autostart/` بحيث يشتغل تلقائياً عند تسجيل الدخول.

## التثبيت على مستوى النظام (يتطلب root)
```bash
make
sudo make install
```

## كيفية الاستخدام
| الإجراء | النتيجة |
|---|---|
| Alt+L | فتح/إغلاق النافذة |
| ضغطة عادية على عنصر | نسخه فوراً للحافظة + إغلاق النافذة (جاهز لـ Ctrl+V) |
| Ctrl+Click على عدة عناصر | تحديد متعدد (بدون نسخ فوري) |
| زر "Copy Selected" | نسخ العنصر المحدد، أو دمج عدة نصوص محددة بسطر لكل واحد |
| زر "Delete Selected" | حذف كل العناصر المحددة |
| زر "Clear All" | مسح كل الحافظة فوراً |
| حقل "Expire (min)" | تعديل مدة الحذف التلقائي بالدقائق (بدون إعادة تشغيل) |

## بنية المشروع
```
clipboard-manager/
├── Makefile
├── install.sh
├── clipboard-manager.desktop   # ملف autostart
├── README.md
└── src/
    ├── main.c        # نقطة الدخول
    ├── ui.c / ui.h    # الواجهة، إدارة النقرات، الأزرار
    ├── storage.c / storage.h   # حفظ/حذف/تنظيف العناصر في /tmp
    └── hotkey.c / hotkey.h     # اختصار Alt+L العام عبر Xlib (XGrabKey)
```

## أفكار توسعة مستقبلية (اختيارية)
- دعم Wayland عبر GNOME Shell extension أو `libinput` لالتقاط الاختصار.
- بحث/تصفية داخل قائمة العناصر (شريط بحث أعلى القائمة).
- تثبيت (Pin) عناصر مهمة بحيث لا تُحذف تلقائياً.
- حفظ العناصر بملف تعريف (config file) بدلاً من قيمة ثابتة داخل الكود لمدة الانتهاء الافتراضية.
- Instance واحدة فقط (منع تشغيل نسخة ثانية من التطبيق بالخطأ) عبر GApplication.
